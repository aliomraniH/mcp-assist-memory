# RESEARCH 1 — Solutions Survey: Mapping Coordination-Memory Challenges (E1–E8 + Plumbing Tax) to Existing Prior Art
(Generated 2026-07-29 from the deep-research pass; in-folder copy for Claude Code context. Full cited version lives in the chat artifact.)

## TL;DR
- Most challenge classes have directly borrowable prior art — the P1–P9 fixes largely re-derive mechanisms in IETF specs (RFC 8785, RFC 9457), production memory systems (Zep/Graphiti bi-temporal validity, Mem0), agent-verification harnesses, and published injection defenses (instruction hierarchy, spotlighting, CaMeL). The novel contribution is the integration into a coordination/verification spine.
- The two thin areas are E2 (authority without falsifiability) and E3 (self-referential verification). Belief-revision theory (Doyle/de Kleer TMS/ATMS, AGM) is mature but almost never wired into LLM memory servers; only 2026 research systems (BeliefMem, MnemeBrain, NeuSymMS, Kumiho) attempt it, none production-proven.
- The plumbing tax is solved practice: lockfiles, stateless Streamable HTTP (protocol default direction), dedicated healthcheck routes, connector-proxy secrets.

## Adopt directly (production-grade)
MCP `isError` conventions (SEP-1303: even validation failures return as in-band tool errors so the model can self-correct); RFC 8785 JCS fingerprints; RFC 9457 problem+json with extension members (`error_code`, `error_category`, `retryable`, `retry_after` — Cloudflare's deployment cut agent token costs ~98%); Anthropic tool-result guidance (`response_format` concise/detailed enum; response caps; pagination/filtering); Zep/Graphiti bi-temporal validity intervals (`t_valid`/`t_invalid` + `t_created`/`t_expired` — the prior art for verdict freshness); JSON-Schema/grammar-constrained decoding at write boundaries (with the "constraint tax" caveat: grammars at the data boundary only, not around the agent loop); Agent Skills / SKILL.md progressive disclosure; `git rev-parse --verify <ref>^{object}` boundary canonicalization (fails closed on ambiguous input; min abbrev 4, auto-scaled); OpenAI instruction hierarchy (arXiv 2404.13208) + read-time untrusted-data wrapping; Microsoft spotlighting (arXiv 2403.14720 — datamarking/encoding drop ASR from >50% to <2%, with honest "not perfectly secure" caveats); OTel GenAI semantic conventions (Development status; covers MCP tool calling; instruments diagnosis, not correctness); stateless Streamable HTTP transport.

## Borrow the design, validate yourself (research-grade)
- E2 belief revision: TMS/ATMS justification networks + AGM minimal change — the real prior art for "re-open rather than re-read". `derived_from` lineage + `tainted_lineage` is already a lightweight justification network; the missing piece is automatic retraction/re-derivation on assumption change. 2026 attempts: NeuSymMS (arXiv 2605.17596), BeliefMem (2605.05583), MnemeBrain, Kumiho — all prototypes.
- Founding-decision review (P1): ADRs with `review_after`/staleness flags; pre-merge verification practice ("staleness flags for specs not reviewed since the last major contract change"); adversarial probing + expiration of unvalidated reflections (memory survey 2603.07670).
- Falsifiable behavioral claims (P2): property-based testing (QuickCheck/Hypothesis) as the falsification-condition mechanism; runtime verification; Agentic PBT (arXiv 2510.09907). No standardized `falsified_by`/`evidence_state` schema exists — MCP Assist would be defining one.
- E3: cross-family judging + judge panels (self-preference bias quantified in arXiv 2410.21819; panel composition caveat 2604.23178); independence-based verification (implementer and test-writer as separate agents from the same contract, no shared history — arXiv 2605.25665); tautological-test guard (test must fail at base, pass at patch, else INVALID_TEST); mutation-based test-adequacy scoring (mutmut; SWE Atlas arXiv 2605.08366 as benchmark gate). Self-test-vs-independent-acceptance delta is not yet a standard metric — closest instrument is SWE Atlas's mutation+regression design.
- E8 memory poisoning: AgentPoison (NeurIPS 2024: ASR-r 81.2% at <0.1% poison rate — scale is not a defense); MINJA (query-only injection); OWASP ASI06 five layers (input moderation, memory sanitization with provenance, trust-aware retrieval, behavioral monitoring, forensics); MemLineage cryptographic write provenance; CaMeL (arXiv 2503.18813 — privileged/quarantined LLM split, 77% AgentDojo with provable security at ~2.8× token cost).

## Genuinely open gaps
(1) No production system couples provenance-verified freshness with belief revision that re-opens prior decisions. (2) Confidence half-life on stored decisions: proposed (MemoryBank/Ebbinghaus for salience), not standardized for correctness. (3) No established falsifiable-claim schema. (4) Self-test-vs-acceptance delta not a standard benchmark metric.

## Staged recommendations (as delivered)
Stage 1 adopt-now: RFC-9457-shaped acks with `retryable`/`remedy`; `isError` on every swallowed condition; compact acks with verbose opt-in; `rev-parse`-style boundary canonicalization; lockfile + stateless HTTP + healthcheck route; read-time wrapping as primary boundary with screens as explicitly non-guaranteed layer.
Stage 2 pilot-and-measure: cross-family verifier + mutation-adequacy commit gate; bi-temporal validity + automatic retraction on assumption change + `review_after` triggers; falsifiable-claim tagging piloted; SKILL.md conventions + server-side envelope completion; CaMeL-style split evaluated for highest-risk write paths.

Maturity caveats: several cited 2026 arXiv IDs are unreviewed preprints; vendor claims (MnemeBrain, Kumiho, etc.) unverified; OTel GenAI still Development status.
